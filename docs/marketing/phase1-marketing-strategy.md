## 一、竞品分析

### 1. 牛客网（Nowcoder）

**定位：** 综合性校招求职平台
**核心功能：**
- 在线笔试题库（算法、编程）
- 真人模拟面试（付费，¥200-500/次）
- 面经分享社区
- 企业内推

**优势：**
- 用户基数大（百万级校招用户）
- 真实面经数据丰富
- 社区活跃度高

**劣势：**
- AI 模拟面试功能弱（主要靠真人）
- 付费门槛高，学生负担重
- 反馈周期长（需要预约真人面试官）
- 缺少个性化分析（基于简历的针对性训练）

---

### 2. LeetCode

**定位：** 算法刷题平台
**核心功能：**
- 算法题库（2000+ 题）
- Mock Interview（随机抽题，计时）
- 企业题库（按公司分类）

**优势：**
- 算法训练专业
- 国际化，支持英文面试
- 题目质量高

**劣势：**
- 只覆盖算法题，不涉及行为面试、系统设计
- Mock Interview 是"做题"而非"对话"
- 无简历解析，无个性化推荐
- 不适合非算法岗位（前端、测试、运维）

---

### 3. 面试鸭（Mianshiya）

**定位：** 面试题库 + 刷题社区
**核心功能：**
- 面试题库（八股文为主）
- 题目分类（按技术栈、公司）
- 用户贡献内容

**优势：**
- 免费
- 题库覆盖广（前端、后端、算法、数据库）
- 社区氛围好

**劣势：**
- 无 AI 模拟面试功能（纯题库）
- 无实时反馈，用户自己对答案
- 无个性化推荐
- 题目质量参差不齐（UGC 内容）

---

### 4. AI 面试助手（通用 LLM 聊天）

**代表：** ChatGPT、文心一言、OpenAI GPT-5.3-codex网页版
**使用方式：** 用户手动输入 prompt："请模拟一场 Java 后端面试"

**优势：**
- 免费或低成本
- 灵活，可以自定义场景

**劣势：**
- 无结构化流程（用户不知道该问什么）
- 无评分机制（只有对话，无反馈）
- 无简历解析（需要用户手动描述背景）
- 无历史记录和进度追踪
- 体验差，像"聊天"而非"面试"

---

### 5. 付费面试辅导课程

**代表：** 各类培训机构、1v1 辅导
**价格：** ¥500-2000/次

**优势：**
- 真人反馈，针对性强
- 可以模拟真实面试压力

**劣势：**
- 价格昂贵，学生负担重
- 需要预约，时间不灵活
- 质量参差不齐（依赖面试官水平）
- 无法高频练习（成本限制）

## 三、差异化定位

### 核心定位（一句话）

> **给校招求职者的 AI 面试陪练：上传简历，20 分钟模拟面试，立即获得评分和改进建议。**

### 三大差异化优势

#### 1. 个性化 — 基于你的简历出题
- **竞品痛点：** 牛客、LeetCode、面试鸭都是通用题库，不管你简历写了什么，题目都一样
- **我们的解法：** 上传简历 → AI 提取技能 → 针对性出题（你写了 Redis，就考 Redis；没写就不考）
- **用户价值：** 不浪费时间在不相关的题目上，聚焦简历上的技能点

#### 2. 结构化 — 完整的面试流程，不是聊天
- **竞品痛点：** 通用 LLM 像"聊天"，用户不知道该问什么；题库平台只有题目，没有流程
- **我们的解法：** 固定流程（自我介绍 → 技能测试 → 场景题），每部分有时间控制和评分标准
- **用户价值：** 模拟真实面试体验，训练时间管理和表达节奏

#### 3. 可视化 — 酷炫的黑金 UI + 数据看板
- **竞品痛点：** 牛客、面试鸭的 UI 很"工具"，LeetCode 很"刷题"，没有"专业感"
- **我们的解法：** 黑金配色 + 雷达图 + 趋势线 + 动效，像金融数据看板
- **用户价值：** 简历截图好看，面试时演示有说服力

## 五、面试话术（3 个版本）

### 版本 1：技术深度（适合技术面试官）

**场景：** 面试官问"介绍一下你的项目"

**回答：**

"这是一个 AI 模拟面试工具，核心挑战是如何让 LLM 生成高质量的面试题和评分。

在架构上，我用 Next.js 做前端，FastAPI 做后端，Supabase 做数据持久化。前后端通过 RESTful API 通信，面试数据存储在 Supabase，简历文件存储在 Cloudflare R2。

在 LLM 集成上，我用了OpenAI GPT-5.3-codex的 API。关键点是 Prompt Engineering：我设计了结构化的 prompt，用 JSON Schema 约束输出格式，确保 LLM 返回的评分包含分数、扣分原因、改进建议三部分。为了控制成本，我实现了缓存机制，相同简历 24 小时内不重复调用 API。

在评分算法上，我定义了四个维度：技术准确性（40%）、表达清晰度（30%）、结构完整性（20%）、深度与广度（10%）。每道题的评分由 LLM 生成，最终汇总成雷达图展示。

技术难点是如何从简历中提取技能并生成针对性题目。我用 LLM 先解析简历，提取技能列表，然后从预设题库中随机抽取相关题目。这样既保证了个性化，又避免了 LLM 生成题目质量不稳定的问题。"

**亮点：**
- 展示全栈能力（前后端分离、数据库、对象存储）
- 展示 LLM 应用能力（Prompt Engineering、成本控制）
- 展示工程思维（缓存、结构化约束、质量保证）

---

### 版本 2：产品思维（适合产品/业务面试官）

**场景：** 面试官问"为什么做这个项目？"

**回答：**

"我在准备校招时发现，市面上的面试准备工具要么太贵（牛客真人模拟面试 ¥200-500），要么体验差（直接用 ChatGPT 聊天，没有结构）。我想做一个免费、随时可用、体验好的工具。

我定义了三个核心价值：

1. **个性化** — 基于简历出题。你写了 Redis，就考 Redis；没写就不考。这样用户不会浪费时间在不相关的题目上。

2. **结构化** — 完整的面试流程（自我介绍 → 技能测试 → 场景题），每部分有时间控制和评分标准。不是"聊天"，是"面试"。

3. **可视化** — 黑金配色的酷炫 UI，雷达图展示各维度得分，趋势线展示进步曲线。简历截图好看，面试时演示有说服力。

在 MVP 阶段，我砍掉了很多功能（比如反问环节、PDF 报告、历史对比），只保留核心流程。目标是让用户在 20 分钟内完成一次完整面试，立即看到结果。

如果要继续做，下一步会加入题库众包（用户贡献题目）、面试录音回放、多人 PK 模式。但现在先验证核心价值。"

**亮点：**
- 展示用户洞察（发现真实痛点）
- 展示产品思维（MVP、功能取舍、价值优先）
- 展示迭代规划（知道下一步做什么）

---

### 版本 3：商业价值（适合 CEO/高管面试官）

**场景：** 面试官问"这个项目有什么商业价值？"

**回答：**

"这个项目的直接目标是展示我的全栈能力，但我也思考过商业化路径。

**市场规模：** 中国每年有 900 万应届毕业生，其中约 200 万是计算机相关专业。假设 10% 愿意为面试准备付费，市场规模约 20 万人。

**竞品分析：** 牛客真人模拟面试 ¥200-500/次，LeetCode 会员 $35/月。我们的成本优势明显（AI 成本 < ¥1/次），可以做到免费或低价（¥9.9/月）。

**变现路径：**
1. **Freemium 模式** — 免费用户每月 3 次面试，付费用户无限次（¥9.9/月）
2. **企业 B2B** — 卖给培训机构、高校就业中心（¥5000-10000/年）
3. **数据变现** — 匿名化的面试数据可以卖给招聘平台（分析校招趋势）

**风险：** 学生付费意愿低，获客成本高。但如果能做到 10 万用户，1% 付费率，月收入约 ¥10 万，可以覆盖成本。

**我的判断：** 这不是一个能做到独角兽的项目，但可以是一个健康的小生意（拉面盈利）。更重要的是，它解决了真实问题，我自己就是用户。"

**亮点：**
- 展示商业思维（市场规模、竞品、变现路径）
- 展示批判性思维（承认风险，不过度乐观）
- 展示务实态度（不追求独角兽，追求解决问题）

## 八、风险与应对

### 风险 1：用户获取成本高，注册转化率低

**症状：**
- GitHub Star 增长缓慢（< 10 Star/周）
- 文章阅读量高，但注册转化率 < 0.1%
- 社区帖子被删除或沉底

**应对措施：**
- ✅ 优化 README，增加演示 GIF 和快速开始指南
- ✅ 在文章中增加"立即体验"按钮，缩短转化路径
- ✅ 提供"无需注册试用"功能（游客模式，限 1 次）
- ✅ 在社区中提供真实价值（面试题库、经验分享），而非硬广

---

### 风险 2：用户注册后不使用，面试完成率低

**症状：**
- 注册用户 100 人，但只有 20 人完成面试
- 用户反馈"不知道怎么用"或"流程太复杂"

**应对措施：**
- ✅ 增加新手引导（首次登录弹窗，3 步教学）
- ✅ 简化上传流程（支持直接粘贴文本，不强制上传文件）
- ✅ 提供示例简历和 JD（一键填充，快速体验）
- ✅ 发送激活邮件（注册后 24 小时未使用，发送提醒）
